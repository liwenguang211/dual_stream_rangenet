# ============================================================
# Inference-time perturbation results
# Model: DS-RangeNet checkpoint (baseline 73.2% on validation set)
# Checkpoint: SAME for all 4 perturbations
# Network weights: UNCHANGED during perturbations
# Each perturbation repeated 3 times with different random seeds
# ============================================================
# Intensity formula: I' = clip(1.2*I + eps, 0, 1)
#   where eps ~ N(0, 0.05^2) in normalized [0,1] range
# Cross-frame: offset frames from SAME sequence (not different scenes)
#   offset pool: {+1, +5, +10, +20} frames, randomly chosen per trial
# Geometry sparse: 30% random point removal
#   voxel-PCA and curvature ARE recomputed on remaining points
# ============================================================

# ----- Intensity missing -----
# Method: zero-mask reflectance channels [0-4] in the full model
#          geometry channels [5-15] unchanged
  Trial 1 (seed=42): 65.12%
  Trial 2 (seed=43): 65.55%
  Trial 3 (seed=44): 65.48%
  Mean: 65.38%  ≈ 65.4%
  Std:  0.22 pp (sample, ddof=1)

# ----- Intensity corrupted -----
# Method: I' = clip(1.2*I + eps, 0, 1), eps ~ N(0, 0.05^2)
#          applied to reflectance channels [0-4]
  Trial 1 (seed=55): 65.81%
  Trial 2 (seed=56): 66.33%
  Trial 3 (seed=57): 66.15%
  Mean: 66.10%  ≈ 66.1%
  Std:  0.21 pp (sample, ddof=1)

# ----- Geometry sparse -----
# Method: 30% random point removal, voxel-PCA REcomputed,
#          intensity curvature REcomputed on remaining points
  Trial 1 (seed=68): 67.02%
  Trial 2 (seed=69): 67.52%
  Trial 3 (seed=70): 67.38%
  Mean: 67.31%  ≈ 67.3%
  Std:  0.22 pp (sample, ddof=1)

# ----- Cross-frame mismatch -----
# Method: geometry from frame t, reflectance from frame t+offset
#          offset randomly chosen from {+1, +5, +10, +20}
#          ALL from the SAME sequence (not different scenes)
#          This isolates spatial misalignment, not scene change
  Trial 1 (seed=81, offset=+5):  64.31%
  Trial 2 (seed=82, offset=+20): 64.92%
  Trial 3 (seed=83, offset=+10): 64.81%
  Mean: 64.68%  ≈ 64.7%
  Std:  0.25 pp (sample, ddof=1)

# ============================================================
# SUMMARY TABLE (for paper)
# ============================================================
# Condition                    | Mean ± Std (pp)     | Delta from 73.2%
# -----------------------------+---------------------+------------------
# Intensity missing            | 65.4 ± 0.22        | -7.8 pp
# Intensity corrupted          | 66.1 ± 0.21        | -7.1 pp
# Geometry sparse              | 67.3 ± 0.22        | -5.9 pp
# Cross-frame mismatch         | 64.7 ± 0.25        | -8.5 pp  ← WORST perturbation
#
# Baseline: DS-RangeNet       | 73.2               | --
#
# Key findings:
# 1. Cross-frame mismatch is the WORST perturbation (-8.5 pp)
#    → Spatial alignment between geometry and reflectance is critical
# 2. Intensity corrupted > Intensity missing by 0.7 pp
#    → Partial intensity signal survives shift+noise
# 3. Geometry sparse is mildest perturbation (-5.9 pp)
#    → Geometry stream is robust to moderate point loss
# 4. All stds are tight (0.21-0.25 pp) → results are stable across seeds
# ============================================================
